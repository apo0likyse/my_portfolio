# Портфолио Елены Ляшок

Первая версия сайта-визитки: адаптивная главная страница, избранные проекты, блок «Обо мне», контакты и три отдельные страницы кейсов.

## Структура

- `index.html` — лендинг с навигацией по разделам.
- `cases/` — самостоятельные страницы кейсов.
- `assets/css/style.css` — типографика, компоненты, состояния наведения и адаптивные стили.
- `assets/js/main.js` — место для лёгких улучшений без зависимости от фреймворка.
- `.github/workflows/pages.yml` — автоматическая публикация на GitHub Pages при обновлении `main`.

## Текущая версия

Профиль и описания трёх кейсов основаны на резюме Елены. Карточки проектов оформлены типографикой; исходные визуальные материалы пока не добавлены. Контактные данные появятся после того, как Елена их передаст.

## Что добавить следующим этапом

- Согласованные превью и изображения для кейсов.
- Почту, Telegram и другие контакты.
- При необходимости — ссылку на PDF-резюме.

## Публикация

В репозитории GitHub откройте **Settings → Pages** и выберите **GitHub Actions** как источник сборки. После этого каждый push в `main` будет запускать публикацию.
